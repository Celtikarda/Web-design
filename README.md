# 🌐 Kişisel Web Sayfam 

Bu proje, front-end geliştirme becerilerimi sergilemek amacıyla sıfırdan tasarladığım kişisel web sayfamdır. Modern web standartları gözetilerek, kullanıcı dostu ve tamamen duyarlı (responsive) bir yapıda geliştirilmiştir.

## 🔗 Canlı Demo
Projeyi canlı olarak incelemek için tıklayınız: https://github.com/Celtikarda/Web-design/tree/main/CSS/%C3%96rnek%20Site

## 🛠️ Kullanılan Teknolojiler

- **HTML5:** Semantik yapı ve erişilebilir (accessible) etiket kullanımı.
- **CSS3:** Flexbox ve CSS Grid ile esnek mizanpaj yönetimi, özel animasyonlar ve mobil uyumlu (responsive) tasarım.
- **JavaScript (ES6+):** Etkileşimli DOM manipülasyonu, olay dinleyicileri (event listeners) ve dinamik içerik yönetimi.

## ✨ Öne Çıkan Özellikler

- 📱 **Tamamen Duyarlı:** Mobil, tablet ve masaüstü ekranlarla kusursuz uyum.
- 🎨 **Modern Arayüz:** CSS kutu modeli (box model) ve konumlandırma özellikleri kullanılarak oluşturulmuş temiz tasarım.
- ⚡ **Etkileşimli Bileşenler:** JavaScript ile yönetilen dinamik menüler, butonlar ve form kontrolleri.
