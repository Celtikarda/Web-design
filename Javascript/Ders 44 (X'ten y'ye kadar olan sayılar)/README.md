# JavaScript Fonksiyon ve While Döngüsü

Bu proje, JavaScript'te fonksiyonlar, parametreler ve `while` döngüsünü pekiştirmek amacıyla oluşturulmuştur.

## Projede Kullanılan Konular

- Fonksiyon tanımlama
- Parametre kullanımı
- `while` döngüsü
- `Number()` ile kullanıcıdan sayı alma
- `prompt()`
- `document.write()`
- `x++` ile değişken değerini artırma

## Nasıl Çalışır?

Program kullanıcıdan iki sayı alır:

- Başlangıç değeri (`X`)
- Bitiş değeri (`Y`)

Daha sonra fonksiyon içerisindeki `while` döngüsü kullanılarak `X` değerinden `Y` değerine kadar olan sayılar ekrana yazdırılır.

## Amaç

JavaScript'te fonksiyon ve döngü kullanımını pratik ederek programlama mantığını geliştirmek.
