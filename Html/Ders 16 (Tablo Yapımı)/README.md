## 📖 Öğrendiğim Kavramlar

- table = Tabloyu oluşturan ana element.
- tr = "table row kısaltmasından gelir. Html sayfamızda tablo satırı oluşturmamızı sağlayan elementtir.
- td = "table data kısaltmasından gelir. Html sayfamıza tabloya bilgi yazmamızı sağlayan elementtir.
- th = "table header" kısaltmasından gelir. Html sayfamıza başlık hücresi (İçeriği genellikle kalın ve ortalanmış gösterir.) yazmamızı sağlayan elementtir.
- caption = Html sayfasında tablonun ne hakkında olduğunu belirtmek için kullanılır.
- thead = "table head" kısaltmasından gelir. Html sayfamızda başlık satırının bölümünü ifade eder. 
- tbody = "table body" kısaltmasından gelir. Html sayfamızda ana veri bölümünü belirtir. Asıl veriler buradadır.
- tfoot ="table foot" kısaltmasından gelir. Html sayfamızda tablonun alt/özet bölümünü belirtir.
