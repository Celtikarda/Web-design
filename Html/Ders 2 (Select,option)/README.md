# 📚 Ders 2

## 🎯 Konu
Liste açmak ve listeden eleman seçmek.


---

## 📖 Öğrendiğim Kavramlar

- Select = Html'de kutu şeklinde liste oluşturan etikettir.
- Option = Oluşturulan listenin elemanlarını oluşturan etikettir.
- Selected = Listeyi açmadan varsayılan seçeneği eklemek için kullanılır.
- Disabled = Listede görünen ama seçilemeyen eleman/elemanlar için kullanılır.
- Selected disabled = Listede varsayılanda görünen ama seçilemeyen elemanlar için kullanılır. 

---

## 📝 Sözdizimi (Syntax)

```HTML

```<select>
    <option value=""></option>
    <option value="" selected></option>
    <option value="" disabled></option>
    <option value="" selected disabled></option>        
</select>
