## 📖 Öğrendiğim Kavramlar

- z-index: ; = Üst üste gelen elemanların hangisinin üstte olacağını belirler.
- position:; = z-index her durumda çalışmaz. O yüzden position: ; kullanılır. 
- position  = Bir elementin nasıl konumlanacağını belirler.
- position: static; = Varsayılan konumdur. Yani yazsak bi şeye fayda etmez. 
- position: relative; = Varsayılan konumunu korur. Bulunduğu yerden oynama yapılabilir. "left: 50px;" gibi oynamalar yapılabilir.
- position: absolute; = Absolute element, kendisine en yakın `position` değeri verilmiş atasını referans alır. **********
- position: fixed; = Varsayılan konumu korur. Sayfayı kaydırsak bile orada sabitlendiğinden dolayı kalır.

## 💡 Mantığı
hangisi ile işimiz varsa onu kullanırız:
Eğer varsayılan olarak ne yazdığını merak edersek --> static.
Eğer bulunduğumuz yerden oynama yapacaksak --> relative.
Eğer kendisine ne yakın "position" değeri verilmiş atasının değerini alır.
Eğer varsayılan konumu korur, sayfa kaydırdığımızda orda kalmasını istersek --> fixed.
