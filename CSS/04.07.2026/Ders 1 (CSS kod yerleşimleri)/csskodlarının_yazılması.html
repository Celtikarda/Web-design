CSS'de 3 farklı şekilde yazılabilir:

1. Inline CSS

Tagların içine yazabildiğimiz css kodları inline olarak adlandırılır.

Bu bir inline css örneğidir

2. Internal CSS

Head etiketi içine yazılan css kodları internal css olarak adlandırılır.

Bu bir internal css örneğidir

3. External CSS

Harici bir css dosyası oluşturup link etiketi ile html dosyasına bağlayarak css kodlarını yazabiliriz.

Bu bir external css örneğidir
