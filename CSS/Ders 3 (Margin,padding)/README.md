## 🎯 Konu

CSS Box Model'e Giriş

---

## 📖 Öğrendiğim Kavramlar

- Border = Kenarlık demektir.
- Width = Genişlik ayarıdır.
- Padding = Kutu ile yazı arasındaki boşluktur.
- Margin = Kutu ile kutu arasındaki boşluktur.
- Block element  = Bulunduğu satırın tamamını kaplayan ve yeni bir satırdan ba başlayan HTML kodudur.

---

## 📝 Sözdizimi

```css
p {
    border-style: solid;
    width: 250px;
    padding: 10px;
    margin: 10px;
}
```

---

## 💡 Mantığı

CSS, HTML elementlerini birer kutu olarak ele alır. Bu kutunun genişliği, kenarlığı, iç boşluğu ve dış boşluğu ayarlanabilir.

---

## ⚠️ Dikkat

- `padding` kutunun içindeki boşluktur.
- `margin` kutunun dışındaki boşluktur.
- `width` içerik alanının genişliğini belirler.
