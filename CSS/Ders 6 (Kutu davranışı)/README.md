## 📖 Öğrendiğim Kavramlar

- overflow: visible; = Varsayılan olan overflow özelliğidir. Yazsak bile bi şi farketmez.
- overflow: hidden: = Kutudan taşan içerik gözükmez sadece kutu içinde kalan kısım gözükür.
- overflow: scrool: = Kutudan taşan içerik kaydırma mantığıyla kutunun sağına kaydırma çubuğu eklenir.
- overflow: auto: = Kutudan taşan içerik varsa scrool, kutudan taşan içerik yoksa hidden özelliğini kullanır.
- overflow-x: auto: = Eğer yatayda (x-ekseninde) taşan içerik varsa scrool, kutudan taşan içerik yoksa hidden özelliğini kullanır.
- overflow-y: hidden: = Eğer dikeyde (y-ekseninde) taşan içerik varsa kutu içinde kalan içerik gözükür, kutudan taşan içerik gözükmez.
- margin: 0 auto; = Bir kutuyu ortalamak için gereken çok önemli bir kod.
---

## 📝 Sözdizimi

```css

 overflow: visible; 
 overflow: hidden;
 overflow: scrool: 
 overflow: auto: 
 overflow-x: auto: 
 overflow-y: hidden: 

---

## 💡 Mantığı
İşimize ne gelirse onu kullanırız:
- Taşarsa kaydırma çubuklu --> Scrool
- Taşarsa kaydırma çubuksuz ama taşan içerik gözükmesin --> Hidden
- Eğer bunları otomatik yapsın istersek --> Auto
- Base özellik --> Visible
- Yatayda taşma varsa --> -x:
- Dikeyde taşmma varsa --> y:
